# Drift

Drift 是只刷交互壁纸的 App：把 `.tendies` 壁纸包刷进 iPhone 的壁纸商店，刷完在锁定屏幕的壁纸选择器里就能选。不下载东西、不拉取手机备份、不改系统其他设置。

发行的是未签名 IPA，自己签名后安装。最低系统 iOS 26.0。

## 能干什么

- 导入 `.tendies` 壁纸包（在 App 里选文件，或在「文件」里用打开方式送进来），导入后一直存着，重启 App 不丢。列表带预览图，点开能逐张看。
- 每个包可以选刷完出现在哪一类（合集 / 精选照片 / Mercury / 容器）。选错了不报错，就是不显示，回来改就行。
- 老格式的包可以转成新格式，导入时会问，之后在包的详情页也能改。
- 一次最多刷 10 张，超了会拦住并说明。
- 刷完能在设置里管理自己刷过的壁纸（不管是哪个软件刷的）：列表就是手机里现在实际有的，选中就能删，删完会再确认一遍真的没了。
- 每次刷入都有记录（用的哪种方式、成功没有、为什么失败），日志可以打包导出。

## 四种刷入方式

选方式的地方有四项：自动选择 / 免注销直刷 / 注销直刷 / 本机直刷。三种真正干活的方式各走各的路，一种用不了只会写明原因，不会偷偷换成另一种。只有「自动选择」会替你挑。

- **自动选择**：按 本机直刷 → 免注销直刷 → 注销直刷 的顺序，挑第一个能用的，并写明挑了哪个、为什么。
- **免注销直刷**：要先配对、开隧道。写入后只重启壁纸的进程，马上生效，不注销、不重启手机。
- **注销直刷**：同样要配对、开隧道。写入后注销一次（界面重启一遍）生效。
- **本机直刷**（实验）：不用配对、不用隧道，直接在手机上写入。要用它，签名得带一个能用的 App Group（见下面「装之前」）。

三种方式写完都会再检查一遍壁纸真的进去了，才报成功；没检查到只会说「已写入、未确认显示」。

## 哪种系统能用哪种

| 手机系统 | 能用的方式 |
|---|---|
| iOS 26.0 – 26.1 | 本机直刷 |
| iOS 26.2 – 27.1 | 三种都能用 |
| iOS 27.2 测试版 1 / 2 | 三种都能用 |
| iOS 27.2 测试版 3 起、27.2.1 | 本机直刷 |
| iOS 27.3 测试版 1 | 本机直刷（实验） |
| iOS 27.3 正式版及更高 | 暂时都用不了 |

## 刷完没生效怎么办

壁纸页有「刷新与生效」卡，两个按钮：

- **结束 PosterBoard**：点一下，App 会先把壁纸进程打开，你再从应用切换器里上滑把它关掉，壁纸就生效了。这个按钮能不能用，跟本机直刷的条件一样（系统版本对、签名带组）；条件不够时会变灰，并写明为什么。
- **注销**：点一下确认，就会注销一次，界面重启完壁纸生效。正在刷入的时候不能用。

用隧道刷的，刷完自动生效，不用管这张卡。

## 装之前要知道的

- **用隧道的方式**（免注销 / 注销直刷）：要先有一份配对文件（向导、壁纸页、设置里都能导入，设置里能换、能删），再装 LocalDevVPN 这类隧道 App 并打开（地址照 App 里写的填），还要连着 Wi-Fi，刷的时候手机保持解锁。
- **用本机直刷**：不用配对也不用隧道，但只有证书签的才行——它带一个能用的 App Group，App 是运行时自己去签名里找能用的组、不写死。免费 Apple ID 直签、SideStore / AltStore 改签都给不了能用的组，本机直刷用不了，其他方式不受影响。把 Drift 套在 LiveContainer 这类 App 里装的，本机直刷也用不了（不是正经装在手机上），隧道那两种能用。用不了的时候，App 会把原因用大白话写出来。
- 免费签名 7 天过期，重装会丢 App 里存的东西（配对文件和导入的包要重新来）。证书更省心。本 App 用不上证书的 VPN 权限。

## 先说清的几件事

- **本机直刷还标着「实验」**：刷进去、上滑关掉进程之后能显示，已经在真机上试过；但重启手机之后还在不在，还没验完。
- **视频壁纸暂时刷不了**：视频页能把视频做成壁纸包，但刷这类包只能用恢复刷，恢复刷现在封着（见下）。
- 带数据库的壁纸包（容器包）也只能用恢复刷，同上，暂时刷不了。
- 本 App 没有下载功能，壁纸包请自己准备；刷入会保留手机上原有的壁纸，没有撤销功能。
- 刷到一半断开（隧道断了、锁屏了）可能留下刷一半的状态，重新刷一遍即可。

## 恢复刷为什么封着

> 恢复刷已封存：2026-11-10 一次恢复刷入在设备重启后把手机恢复了出厂设置、数据全部丢失。查清原因并在备用机上验证「从设备拉到真备份」之前不开放：入口可见，但没有任何可执行的恢复代码。视频壁纸、重置商店与带数据库的容器包暂时都刷不了；三条直刷通道不受影响。

## 自己编译

需要 Mac（Xcode 26）和 Rust：先给 Rust 装 `aarch64-apple-ios` 目标，跑 `scripts/build-airlift-ffi-ios.sh --install`，再用 XcodeGen 生成工程、`scripts/build-ipa.sh Release` 打包。仓库的 GitHub Actions 已经包含这些步骤，发行版里有打好的包。

## 源码和署名

许可证 AGPL-3.0。

- 隧道写入的核心来自 [AirCard-iOS](https://github.com/Mak5er/AirCard-iOS)（作者 Mak5er，MIT 许可证）；在它之上加的「只重启壁纸进程就生效」和「查看、删除商店里的壁纸」是本项目自己扩展的。
- 本机直刷用的是 [forcequitOS/worse_query](https://github.com/forcequitOS/worse_query)（GPL-3.0），写入商店时的目录找法参考了 3106 的公开做法。
- 详细的署名和许可证在仓库根目录的 `NOTICE` 和各源码目录里。
