# Drift

Drift：只刷交互壁纸的独立应用。基于 GoldenNugget（AGPL-3.0）移植壁纸与连接层代码，新增按 iOS 版本自动判断刷入方式（直刷免注销 / 本机直刷 / AirLift 直刷 / 恢复式）；删除调整、钱包、状态栏等全部其他功能，仅保留壁纸包与视频壁纸刷入，后续可能会开发新功能。发布未签名 IPA 供自签。

## 功能

### 壁纸包刷入（主功能）

- 导入 `.tendies` 壁纸包：用系统文件选择器导入，也可以在「文件」App 里对壁纸包点打开方式直接送进 Drift；导入后存在 App 内，重启不丢。
- 已导入包列表带**预览图**：导入时从包里提取并缓存（优先包内现成的预览/海报图，其次描述符里最大的静态图，视频类取首帧）；点开包能逐张看预览。纯动画、没有任何静态图的包用占位图显示。
- 每个包可选归属类型（合集 / 精选照片 / Mercury / 容器）；选错不报错、只是不显示。
- 旧格式壁纸包导入时询问是否转现代格式（带总开关，默认开）。
- 一次所选包的描述符合计上限 10 张，超了会拦下并说明。
- 带商店数据库的容器包会标「风险高」——只能走恢复式。
- **重置壁纸商店**：三种清理（合集 / 精选照片 / 图库缓存）＋完全重置，只能走恢复式、刷完重启，与普通刷入不能同一次进行。

### 视频壁纸（单独一页）

- 导入视频＋定格帧图片；循环 / 倒放 / 前景层开关，帧计算方式可选。
- 循环模式把视频逐帧存下（最多 400 帧、原分辨率）；非循环是实况照片式（视频＋定格帧）。
- 视频壁纸只能走恢复式，刷完重启。

### 直刷免注销（回环配对）

隧道通道：通过配对文件和 LocalDevVPN 打开 AirTraffic/Books 写入事务，一次写入一个描述文件并同时写好刷新偏好；写完后只让设备重启 PosterBoard 守护进程（DVT ProcessControl），由 launchd 拉起并重新读取商店——**不注销、不重启**，其余 App 不受影响。

- 支持 iOS 26.0–27.1 及 27.2 测试版 1 / 2（按构建号判断：24B5084k、24B5089g）；27.2 测试版 3 起被系统修复。
- 需要配对文件、LocalDevVPN，设备保持解锁。
- 只添加描述文件，不能重置商店；和 AirLift 一样，视频壁纸和带数据库的容器包仍只能走恢复式。
- 免注销刷新未确认时（隧道断开、服务不可用等）会自动回落到注销，不会留下写好了却看不见的壁纸。
- 免费签也能用这一条：它不需要 App Group。

### 本机直刷

隧道之外的刷入通道：基于 [forcequitOS/worse_query](https://github.com/forcequitOS/worse_query)，在 App 进程内取得 PosterBoard 容器的沙盒扩展，直接把描述文件写进去。**写入不用配对文件、不用 LocalDevVPN、不用隧道**。

- 支持 iOS 26.0–26.7.2 和 27.0–27.2。这也让原本刷不了的 26.0/26.1，以及在 27.2 上被 AirLift 拒之门外的设备有了直刷通道。
- 生效方式在写完后判定：当时配对文件、LocalDevVPN、Wi-Fi 三样齐全的话，借隧道只重启 PosterBoard 守护进程，**免注销生效**（刷新没确认时会自动再检测一次）；三样不齐就只提示「壁纸已写入」，并给出手动注销按钮，点不点由用户决定，App 不自动注销。
- 需要签名里带 App Group：App 会在运行时读取签名实际授予的 App Group 名单，用第一个能打开的，不再写死组名——付费证书（哈希组名）、开发者注册的组、SideStore / AltStore 改签的组都可以；免费 Apple ID 直签拿不到 App Group。没有可用组时菜单里的本机直刷会置灰，自动判断也会回落到其他方式，不会把一次刷入做到一半才失败。
- 和 AirLift 一样只添加描述文件，不能重置商店；视频壁纸和带数据库的容器包仍然只能走恢复式。
- 写入位置与 AirLift 相同：`…/PRBPosterExtensionDataStore/<版本>/Extensions/<provider>/descriptors/<随机 UUID>`，描述符的三个身份字段会在写入前一起改写。

### 自动判断刷入方式

检测分两类前提、互不绑架：本机直刷只看 App 自身的系统版本和签名授予的 App Group（不看配对、隧道、Wi-Fi）；直刷免注销与 AirLift 必须真读到设备的系统版本＋构建号才算数，读不到就判不可用并写明原因。刷入前会再复检一次，结果和逐档理由都显示在刷入卡上：

- 视频壁纸、重置商店、带数据库的容器包 → 强制恢复式（硬限制，手动选直刷会被拦下并说明；恢复式停用期间会明确报「现在刷不了」）；
- 本机直刷可用 → 本机直刷（不配对、不重启）；
- 否则有配对且系统在范围内 → 直刷免注销（只刷新 PosterBoard，不注销）；
- 否则系统在 AirLift 范围内且有配对 → AirLift 直刷（只注销不重启）；
- 都不可用 → 回落恢复式（停用期间报「现在刷不了」）。
- 自动判断之外也可以手动改方式：手动选的方式用不了时，按同一顺序回落到下一个可用的，并写明改判原因（硬限制不放行）。

### 配对与连接

- 配对文件导入是独立功能：向导、壁纸页、设置页都有入口，设置页可更换/删除。认 `.mobiledevicepairing` / `.mobiledevicepair` / `.mobiledeviceconfig` 三种格式，也支持在「文件」App 里用打开方式送入。
- 配对文件来源：在电脑上用 iLoader 配对后导出（.plist 或 .mobiledevicepairing）传入；也可以用 idevicepair / Sideloadly 配对后传入；iOS 27 起可用 App 内无线自配对（iOS 26 没有这条路）。
- 隧道只用 LocalDevVPN（或同类隧道 App），地址固定使用默认值（本机 10.7.1.1、对端 10.7.0.1、端口 62078、前缀 24），App 只做检测、不可修改。
- 首次设置向导：先检测本机直刷——可用时配对与隧道是可选步（想用隧道方式时再配），不可用时才走配对＋隧道流程；隧道状态实时显示。

### 记录

- 刷入记录（时间、方式、实际生效方式、成功/失败与原因）、运行日志查看、诊断导出（diagnostics.txt ＋ App 日志 ＋ minimuxer 日志，系统分享）。

### 界面

- 四个页面：壁纸 / 视频 / 说明 / 设置，简约浅色风；**深色模式跟随系统**，浅色、深色各一套，桌面图标也有深色变体。

## 系统范围

最低系统 iOS 26.0。

| 设备系统 | 普通壁纸包 | 刷完 | 视频壁纸 |
|---|---|---|---|
| iOS 26.0 – 26.1 | 直刷免注销 / 本机直刷* | 免注销 / 见注 | 恢复式（重启） |
| iOS 26.2 – 27.1 | 直刷免注销 / AirLift / 本机直刷* | 免注销 / 只注销 / 见注 | 恢复式（重启） |
| iOS 27.2 beta 1 / beta 2 | 直刷免注销 / AirLift / 本机直刷* | 免注销 / 只注销 / 见注 | 恢复式（重启） |
| iOS 27.2 beta 3 起（含 27.2 正式版） | 本机直刷* | 见注 | 恢复式（重启） |
| iOS 27.3 以上 | 恢复式 | 重启 | 恢复式（重启） |

表里的「直刷免注销」指回环配对通道；「AirLift」指 AirLift 通道。两者都需要配对。

* 本机直刷：iOS 26.0–26.7.2 与 27.0–27.2 可用，写入不需要配对或隧道，但要求签名带可用的 App Group（运行时发现实际授予的组）。它的生效方式看写完当时的条件：配对、LocalDevVPN、Wi-Fi 三样齐全时免注销生效，否则只提示并提供手动注销按钮（见「本机直刷」一节）。


## 使用前提

- 一台已配对的设备＋配对文件（见上）。
- LocalDevVPN（或同类隧道 App）按 App 给的地址填好并保持开启；隧道在 App 启动后才连上的，把 App 关掉重开一次。需要 Wi-Fi 可用。
- 签名：Apple ID 免费签、付费 p12 证书都能用，功能无差别。免费签有 7 天过期、换 Bundle ID 重装会丢 App 内数据（配对与已导入的包要重新导入）；付费证书更稳定。本 App 没有自己的隧道扩展，用不上 p12 的 VPN 权限。
- 唯一例外是本机直刷：它需要签名带 App Group——付费证书、SideStore / AltStore 改签都可以，App 会在运行时发现签名实际授予的组并使用；免费 Apple ID 直签拿不到 App Group。没有可用组时其他方式不受影响。

## 风险与边界（只标注，不做安全网）

- 本 App **没有下载功能**，壁纸包请自备；**没有备份功能**，恢复式只是内部刷入通道，刷入会保留设备上已有的壁纸。
- 刷入时请保持设备解锁、隧道开着、配对有效；中途断开可能留下刷一半的状态。
- 容器包可能弄乱壁纸商店索引；本 App 没有回滚，清乱了用「重置壁纸商店」。
- 系统升级后直刷范围可能变化（例如 27.2 beta 3 起已被关闭），App 会按读到的版本自动回落恢复式。

## 与上游 GoldenNugget 的区别

本项目是修改版，基于 [GoldenNugget-Mobile](https://github.com/GoldenNugget-Team/GoldenNugget-mobile) 的壁纸（PosterBoard）与连接层代码移植，独立工程，不是上游的分支版本。

**新增**

- 独立四页界面（壁纸 / 视频 / 说明 / 设置）与独立会话层；
- 壁纸包预览图提取与缓存、包详情页逐张预览；
- 直刷免注销通道：AirTraffic/Books 写入事务与 PosterBoard 单守护进程刷新，刷完免注销（源码在 `Nugget/Core/PosterBoardDirect.swift`、`PosterRefresh.swift`）；
- 本机直刷通道：移植 [worse_query](https://github.com/forcequitOS/worse_query)，不配对、不开隧道直接写 PosterBoard 容器（GPL-3.0，与本项目 AGPL-3.0 兼容，源码在 `WorseQuery/`）；
- 刷入方式判断卡：结果＋理由展示，手动改方式＋硬限制拦截；
- `.tendies` 与配对文件的「打开方式」文件关联导入。

**删除**

- 全部调整项（SpringBoard 选项、守护进程管理、密码主题、钱包、状态栏、模板与预设、社区下载、媒体、文件页、在线更新等）与对应页面；
- 内置回环隧道（em_proxy）——隧道只用 LocalDevVPN；
- 跳过设置助手等随调整附带的行为。

## 构建

源码构建需要云端 Mac（Xcode 26）。直刷与免注销刷新新增了 Rust FFI，仓库里的预编译归档可能落后于源码，所以先装 Rust 的 `aarch64-apple-ios` target，运行 `scripts/build-airlift-ffi-ios.sh --install` 重建并安装归档，再用 XcodeGen 生成工程、`scripts/build-ipa.sh Release` 产出未签名 IPA（CI 的构建流程已经包含这一步）。本仓库的发行版提供已构建的未签名 IPA，下载后用自己的证书/账号自签安装。

界面文案为中文优先，直接以中文书写；继承自上游的向导等页面沿用其字符串目录。
