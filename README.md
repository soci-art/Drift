# Drift

Drift 是只刷交互壁纸的独立应用：把 `.tendies` 壁纸包刷进 iPhone 的壁纸商店（PosterBoard），刷完在锁定屏幕壁纸选择器里选用。不下载、不拉取设备备份、不改系统其他设置。发布未签名 IPA，供自签安装。最低系统 iOS 26.0。

## 功能

### 壁纸包

- 导入 `.tendies` 壁纸包：用系统文件选择器导入，也可以在「文件」App 里对壁纸包点打开方式直接送进 Drift；导入后存在 App 内，重启不丢。
- 已导入包列表带**预览图**（导入时从包里提取并缓存）；点开包能逐张看预览。纯动画、没有任何静态图的包用占位图显示。
- 每个包可选刷完出现的位置类型（合集 / 精选照片 / Mercury / 容器）；选错不报错、只是不显示，回来改就行。
- 旧格式（WWDC_2022）壁纸包可转换成现代格式：导入时询问，答案按包记住，之后可在包详情页更改。
- 一次所选包的描述符合计上限 10 张，超了会拦下并说明。
- 带商店数据库的容器包会标「含数据库 · 风险高」——只能走恢复刷（见下「恢复刷已封存」）。

### 刷入方式（四项）

名称固定为：自动选择 / 免注销直刷 / 注销直刷 / 本机直刷。三条通道彼此独立，各自实现写入与生效；一条通道不可用只会写明原因，**不会自动改走另一条**。只有「自动选择」会在三条之间挑选。

**自动选择** 是判定层，不是通道：按 本机直刷 → 免注销直刷 → 注销直刷 的顺序取第一条前提满足的通道，并在卡上写明这次选了哪条、为什么。手动选定某条通道后，它的前提不满足就是不可用（该行写明原因），不会被自动替换。

**免注销直刷**（隧道）：在一次隧道事务内同时写入描述符与「重新加载偏好」文件，写完只重启 PosterBoard 守护进程，系统重新拉起它时重读商店——刷完即生效，不注销、不重启，其余 App 不受影响。刷新未确认时只提示并给出手动注销按钮，App 不自动注销。写前先枚举设备上商店的实际内容核对结构，写后再枚举一次核验。

**注销直刷**（隧道）：通过配对隧道逐张写入描述符，写完统一注销生效。与免注销直刷共用底层传输，但写入与生效流程各自独立。同样有写前核对与写后核验。

两条隧道通道必须已配对、LocalDevVPN 隧道连通，并真读到设备的系统版本＋构建号；读不到设备身份时一律不可用并写明原因，不拿 App 自己的版本冒充。支持范围：iOS 26.2–27.1 与 27.2 测试版 1 / 2（按构建号 24B5084k、24B5089g 判断），27.2 测试版 3 起不可用。

**本机直刷**（实验）：基于 [forcequitOS/worse_query](https://github.com/forcequitOS/worse_query)，在 App 进程内取得 PosterBoard 容器的访问权，直接把描述符写进商店容器——**不用配对文件、不用 LocalDevVPN、不用隧道**。写入参照 3106 的做法：扫描商店真实的数字代际目录，优先选已包含本包所需全部分发者的代际；落点取描述符自报的分发者标识，没有重映射表；同目录暂存 → 校验文件数与字节数 → 原子改名 → fsync 落地；描述符的数字标识在三处一起重写，Mercury 描述符保留原文件夹名。不写偏好文件、不写待处理更新清单、不动商店数据库。每次写入留一条回执。

本机直刷只看本机前提：App 自身的系统版本（含构建号）在范围内，且签名授予了一个能打开的 App Group。App 在运行时读取签名实际授予的组名单、逐个试开、用第一个能打开的，不写死组名——付费证书的哈希组名、开发者后台注册的组、SideStore / AltStore 改签的组都可以；免费 Apple ID 直签拿不到 App Group，此时其他方式不受影响。支持范围：iOS 26.0–26.7.2、27.0–27.2.1，以及 27.3 测试版 1（24C5037i，按实验对待；依据为上游公开声明，未经真机验证）。

**核验口径**：三条通道都是写后核验——只有确认描述符已在商店在册才报「完成」；没核对上只报「已写入、未确认显示」，不冒充成功。

### 刷新与生效

壁纸页有「刷新与生效」卡，刷完没生效时用：

- **结束 PosterBoard**：App 先把 PosterBoard 拉起来，你再从应用切换器上滑关闭它，系统重新拉起后壁纸生效。按本机前提判定可用性（与本机直刷同一套：系统在范围＋App Group 可用），不满足就置灰并写明原因。
- **注销**：确认后立即注销，界面重启一遍后壁纸生效，所有通道可用；正在刷入时不可用。

隧道通道刷完会自动处理生效，不用这张卡。

### 管理刷入的壁纸

设置页可管理**自己刷入的壁纸**（不限哪个软件刷的）：以设备上壁纸商店的实际在册清单为准，列出合集 / Mercury / 照片三类分发者下的描述符；系统与功能型分发者（渐变、天气等）不列、不可删。

- 删除走哪条路由由检测决定：隧道在（已配对＋LocalDevVPN 连通＋读到设备）走隧道删除；隧道不在但本机可用走本机删除；都不行则删不了并写明原因，页面会写明本次走哪条。
- 可勾选多条，确认弹窗逐条列明将删什么；没有「全选清空」入口。删后重新核验不在册才报「已删除」，否则报「已删除、未确认」。
- Drift 自己刷入的（3.0.1 起三个通道都留回执）在刷入记录里也能找到并删除。

### 记录与日志

- 刷入记录：每次刷入与管理删除的时间、所选方式、实际通道、生效方式、核验结论与成败原因；可一键清空（只清记录，不删壁纸；回执不随清空删除，它是删除本机刷入的凭证）。
- 运行日志可在 App 内查看，也可导出日志包（诊断信息＋App 日志＋连接日志）走系统分享。

### 视频壁纸

视频页可导入视频＋定格帧图片，生成视频壁纸包（循环 / 倒放 / 前景层等选项）。但视频壁纸只能走恢复刷，恢复刷封存期间**暂时刷不了**（见下）。

### 恢复刷已封存

> 恢复刷已封存：2026-11-10 一次恢复刷入在设备重启后把手机恢复了出厂设置、数据全部丢失。查清原因并在备用机上验证「从设备拉到真备份」之前不开放：入口可见，但没有任何可执行的恢复代码。视频壁纸、重置商店与带数据库的容器包暂时都刷不了；三条直刷通道不受影响。

## 系统范围

最低系统 iOS 26.0。

| 设备系统 | 可用通道 | 生效方式 |
|---|---|---|
| iOS 26.0 – 26.1 | 本机直刷* | 上滑关闭 PosterBoard |
| iOS 26.2 – 27.1 | 免注销直刷 / 注销直刷 / 本机直刷* | 免注销 / 注销 / 上滑关闭 |
| iOS 27.2 测试版 1 / 2 | 免注销直刷 / 注销直刷 / 本机直刷* | 免注销 / 注销 / 上滑关闭 |
| iOS 27.2 测试版 3 起、27.2.1 | 本机直刷* | 上滑关闭 PosterBoard |
| iOS 27.3 测试版 1（24C5037i） | 本机直刷*（实验） | 上滑关闭 PosterBoard |
| iOS 27.3 正式版及更高 | 无可用通道 | — |

\* 本机直刷要求签名授予可用的 App Group（运行时发现，不写死组名）；没有可用组时这一档没有可用通道。

## 使用前提

- **隧道通道**：配对文件＋LocalDevVPN（或同类隧道 App）。配对文件认 `.plist` / `.mobiledevicepairing` 等格式，向导、壁纸页、设置页都有导入入口，设置页可更换 / 删除；来源可用电脑上的配对工具导出后传入。LocalDevVPN 地址按 App 内给的默认值填（本机 10.7.1.1、对端 10.7.0.1、端口 62078），需 Wi-Fi 可用，刷入时设备保持解锁。
- **本机直刷**：不需要配对与隧道，只需要系统在范围内＋签名带可用的 App Group。
- **首次设置向导**：先检测本机直刷——可用时配对与隧道是可选步，不可用时才走配对＋隧道流程；隧道状态实时检测，App 打开之后再连上隧道也会自动识别。

## 安装

从本仓库发行版下载未签名 IPA，用自己的证书 / 账号自签安装（付费 p12 证书、AltStore、SideStore、Sideloadly 等均可）。签名方式功能无差别，唯一例外是本机直刷需要签名带 App Group（见上）。免费签 7 天过期，重装会丢 App 内数据（配对与已导入的包要重新导入）；付费证书更稳定。本 App 没有自己的隧道扩展，用不上证书的 VPN 权限。

## 风险与边界

- 本 App 没有下载功能，壁纸包请自备；刷入会保留设备上已有的壁纸，本 App 没有回滚功能。
- 刷入时请保持设备解锁、隧道开着（隧道通道）、配对有效；中途断开可能留下刷一半的状态。
- 选错出现位置不报错、只是不显示，回来改包的类型即可。
- 系统升级后各通道范围可能变化（例如隧道通道在 27.2 测试版 3 起已被系统关闭），对应通道会判为不可用并写明原因；本机直刷按自己的范围单独判断。
- 本机直刷的重启存活尚未完成验证（刷入与上滑关闭后显示已在真机证通），故仍标「实验」。

## 构建

源码构建需要 Mac（Xcode 26）。先装 Rust 的 `aarch64-apple-ios` target，运行 `scripts/build-airlift-ffi-ios.sh --install` 重建并安装 FFI 归档，再用 XcodeGen 生成工程、`scripts/build-ipa.sh Release` 产出未签名 IPA。仓库的 GitHub Actions 流程已包含这几步，发行版提供构建好的未签名 IPA。

界面文案为中文优先，直接以中文书写。

## 来源与许可证

AGPL-3.0。设备写入的隧道核心源自 [AirCard-iOS](https://github.com/Mak5er/AirCard-iOS)（Mak5er 著，MIT 许可证）：回环隧道、配对、同步写入与注入；其上的免注销生效（只重启 PosterBoard）、壁纸商店枚举与删除为 Drift 一侧的扩展实现。本机直刷通道基于 forcequitOS/worse_query（GPL-3.0，与 AGPL-3.0 兼容），布局扫描参照 3106 的公开实现。署名与许可证细节见仓库根目录 `NOTICE` 与各 vendored 目录内的说明。

1.x 版本曾移植 GoldenNugget 的壁纸与连接层代码；2.0.0 起引擎已整体更换为上述核心，旧代码不再保留。
