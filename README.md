# Drift

Drift：只刷交互壁纸的独立应用。基于 GoldenNugget（AGPL-3.0）移植壁纸与连接层代码，提供四种刷入方式：自动选择 / 免注销直刷 / 注销直刷 / 本机直刷，另有封存的恢复刷；删除调整、钱包、状态栏等全部其他功能，仅保留壁纸包与视频壁纸刷入。发布未签名 IPA 供自签。

## 功能

### 壁纸包刷入（主功能）

- 导入 `.tendies` 壁纸包：用系统文件选择器导入，也可以在「文件」App 里对壁纸包点打开方式直接送进 Drift；导入后存在 App 内，重启不丢。
- 已导入包列表带**预览图**：导入时从包里提取并缓存（优先包内现成的预览/海报图，其次描述符里最大的静态图，视频类取首帧）；点开包能逐张看预览。纯动画、没有任何静态图的包用占位图显示。
- 每个包可选归属类型（合集 / 精选照片 / Mercury / 容器）；选错不报错、只是不显示。
- 旧格式壁纸包导入时询问是否转现代格式（带总开关，默认开）。
- 一次所选包的描述符合计上限 10 张，超了会拦下并说明。
- 带商店数据库的容器包会标「风险高」——只能走恢复刷。
- **重置壁纸商店**：三种清理（合集 / 精选照片 / 图库缓存）＋完全重置，只能走恢复刷、刷完重启，与普通刷入不能同一次进行。

### 视频壁纸（单独一页）

- 导入视频＋定格帧图片；循环 / 倒放 / 前景层开关，帧计算方式可选。
- 循环模式把视频逐帧存下（最多 400 帧、原分辨率）；非循环是实况照片式（视频＋定格帧）。
- 视频壁纸只能走恢复刷（封存），刷完重启。

### 刷入方式（四项）

名称固定为：自动选择 / 免注销直刷 / 注销直刷 / 本机直刷。三条通道彼此独立，各自实现写入与生效；一条通道不可用只会写明原因，不会自动改走另一条。只有「自动选择」会在三条之间挑选。

**自动选择** 是判定层，不是通道：按 本机直刷 → 免注销直刷 → 注销直刷 的顺序，取第一条前提满足的通道，并在卡上写明这次选了哪条、为什么。手动选定某条通道后，它的前提不满足就是不可用（该行写明原因、刷入不可执行），不会自动替换成别的通道。

**免注销直刷**（隧道）：通过配对文件和 LocalDevVPN 打开一次 AirTraffic/Books 事务，同时写入描述文件与「重新加载偏好」文件；写完后只让设备重启 PosterBoard 守护进程（DVT ProcessControl），由 launchd 拉起并重新读取商店——**不注销、不重启**，其余 App 不受影响。刷新未确认时只提示「已写入、未确认生效」并给出手动注销按钮，App 不自动注销，也不改走注销直刷。需要配对文件、LocalDevVPN，设备保持解锁；只添加描述文件，不能重置商店。

**注销直刷**（隧道）：通过配对隧道逐张写入描述文件，写完统一注销生效。它与免注销直刷共用底层传输（配对、隧道、FFI），但写入与生效流程各自独立，不借对方的定点重启冒充注销。需要配对文件、LocalDevVPN，设备保持解锁；只添加描述文件，不能重置商店。

**本机直刷**（实验）：基于 [forcequitOS/worse_query](https://github.com/forcequitOS/worse_query)，在 App 进程内取得 PosterBoard 容器的沙盒扩展，直接把描述文件写进去。**写入不用配对文件、不用 LocalDevVPN、不用隧道**。按 3106 的做法：扫描商店真实的数字代际目录，优先选已包含本包所需全部分发者的代际；落点取描述符自报的 `extensionBundleIdentifier`，没有重映射表；同目录暂存 → 校验文件数/字节数 → 原子改名 → fsync；描述符的数字标识在三处一起重写，Mercury 保留原文件夹名并做重名避让。不写偏好文件、不写 PendingDescriptorUpdates、不动 sqlite。

本机直刷刷完不做任何自动生效动作：提示「打开应用切换器，向上轻扫关闭 PosterBoard」，系统重新拉起 PosterBoard 时会重读商店，壁纸生效。每次写入留一条回执（落点与标识），设置页「本机直刷写入记录」可按回执删除，删前列明将删什么，删后重新枚举核验已不在册。

两条隧道通道必须已配对、隧道连通，并真读到设备的系统版本＋构建号；读不到设备身份时都不可用并写明原因，不拿 App 自己的版本冒充。它们的支持范围是 iOS 26.2–27.1 与 27.2 测试版 1/2（按构建号 24B5084k、24B5089g 判断），27.2 测试版 3 起被系统修复。

本机直刷只看本机前提：App 自身的系统版本（含构建号）在范围内，且签名授予了一个能打开的 App Group。App 会在运行时读取签名实际授予的组名单，用第一个能打开的，不写死组名——付费证书、开发者注册的组、SideStore / AltStore 改签的组都可以；免费 Apple ID 直签拿不到 App Group。

视频壁纸、重置壁纸商店、带数据库的容器包都只能走恢复刷；恢复刷已封存（入口可见不可选、零执行代码），这类内容现在刷不了。

### 配对与连接

- 配对文件导入是独立功能：向导、壁纸页、设置页都有入口，设置页可更换/删除。认 `.mobiledevicepairing` / `.mobiledevicepair` / `.mobiledeviceconfig` 三种格式，也支持在「文件」App 里用打开方式送入。
- 配对文件来源：在电脑上用 iLoader 配对后导出（.plist 或 .mobiledevicepairing）传入；也可以用 idevicepair / Sideloadly 配对后传入；iOS 27 起可用 App 内无线自配对（iOS 26 没有这条路）。
- 隧道只用 LocalDevVPN（或同类隧道 App），地址固定使用默认值（本机 10.7.1.1、对端 10.7.0.1、端口 62078、前缀 24），App 只做检测、不可修改。
- 首次设置向导：先检测本机直刷——可用时配对与隧道是可选步（想用隧道方式时再配），不可用时才走配对＋隧道流程；隧道状态实时显示。

### 记录

- 刷入记录（时间、方式、实际生效方式、成功/失败与原因）、运行日志查看、诊断导出（diagnostics.txt ＋ App 日志 ＋ minimuxer 日志，系统分享）。

### 界面

- 四个页面：壁纸 / 视频 / 说明 / 设置，简约浅色风；**深色模式跟随系统**，浅色、深色各一套，桌面图标也有深色变体。

## 系统范围

最低系统 iOS 26.0。

| 设备系统 | 免注销直刷 | 注销直刷 | 本机直刷 | 视频壁纸 |
|---|---|---|---|---|
| iOS 26.0 – 26.1 | 不可用（隧道下限 26.2） | 不可用（隧道下限 26.2） | 可用* | 恢复刷（封存） |
| iOS 26.2 – 27.1 | 可用 | 可用 | 可用* | 恢复刷（封存） |
| iOS 27.2 测试版 1 / 2 | 可用（按构建号） | 可用（按构建号） | 可用* | 恢复刷（封存） |
| iOS 27.2 测试版 3 起、27.2 正式版 | 不可用 | 不可用 | 可用* | 恢复刷（封存） |
| iOS 27.2.1 | 不可用 | 不可用 | 可用* | 恢复刷（封存） |
| iOS 27.3 测试版 1（24C5037i） | 不可用 | 不可用 | 可用*（实验） | 恢复刷（封存） |
| iOS 27.3 正式版及更高 | 不可用 | 不可用 | 不可用 | 恢复刷（封存） |

* 本机直刷要求签名授予可用的 App Group（运行时发现实际授予的组）；没有可用组时这一档不可用。它不需要配对或隧道，刷完按提示上滑关闭 PosterBoard 生效，App 不自动注销。27.3 测试版 1 的依据是公开声称，未经我方真机实测，按实验对待。

## 使用前提

- 走两条隧道通道时：一台已配对的设备＋配对文件（见上），以及 LocalDevVPN（或同类隧道 App）按 App 给的地址填好并保持开启；本机直刷不需要这两样。
- LocalDevVPN 需要 Wi-Fi 可用；隧道在 App 启动后才连上的，把 App 关掉重开一次。需要 Wi-Fi 可用。
- 签名：Apple ID 免费签、付费 p12 证书都能用，功能无差别。免费签有 7 天过期、换 Bundle ID 重装会丢 App 内数据（配对与已导入的包要重新导入）；付费证书更稳定。本 App 没有自己的隧道扩展，用不上 p12 的 VPN 权限。
- 唯一例外是本机直刷：它需要签名带 App Group——付费证书、SideStore / AltStore 改签都可以，App 会在运行时发现签名实际授予的组并使用；免费 Apple ID 直签拿不到 App Group。没有可用组时其他方式不受影响。

## 风险与边界（只标注，不做安全网）

- 本 App **没有下载功能**，壁纸包请自备；**没有备份功能**，恢复刷只是内部的封存入口，刷入会保留设备上已有的壁纸。
- 刷入时请保持设备解锁、隧道开着、配对有效；中途断开可能留下刷一半的状态。
- 容器包可能弄乱壁纸商店索引；本 App 没有回滚，清乱了用「重置壁纸商店」。
- 系统升级后隧道直刷范围可能变化（例如 27.2 测试版 3 起已被关闭），对应通道会判为不可用并写明原因；本机直刷按自己的范围单独判断。

## 与上游 GoldenNugget 的区别

本项目是修改版，基于 [GoldenNugget-Mobile](https://github.com/GoldenNugget-Team/GoldenNugget-mobile) 的壁纸（PosterBoard）与连接层代码移植，独立工程，不是上游的分支版本。

**新增**

- 独立四页界面（壁纸 / 视频 / 说明 / 设置）与独立会话层；
- 壁纸包预览图提取与缓存、包详情页逐张预览；
- 免注销直刷通道：AirTraffic/Books 写入事务与 PosterBoard 单守护进程刷新，刷完免注销（源码在 `Drift/Core/PosterBoardDirect.swift`、`PosterRefresh.swift`）；
- 注销直刷通道：隧道逐张写入后注销生效（源码在 `Drift/Core/PosterBoardAirlift.swift`）；
- 本机直刷通道：移植 [worse_query](https://github.com/forcequitOS/worse_query)，不配对、不开隧道直接写 PosterBoard 容器（GPL-3.0，与本项目 AGPL-3.0 兼容，源码在 `Drift/Core/PosterBoardLocal.swift`、`Drift/Core/PosterBoardLocalReceipts.swift`）；
- 刷入方式判断卡：四项方式、逐通道理由与实时状态、自动选择结果；
- `.tendies` 与配对文件的「打开方式」文件关联导入。

**删除**

- 全部调整项（SpringBoard 选项、守护进程管理、密码主题、钱包、状态栏、模板与预设、社区下载、媒体、文件页、在线更新等）与对应页面；
- 内置回环隧道（em_proxy）——隧道只用 LocalDevVPN；
- 跳过设置助手等随调整附带的行为。

## 构建

源码构建需要云端 Mac（Xcode 26）。直刷与免注销刷新新增了 Rust FFI，仓库里的预编译归档可能落后于源码，所以先装 Rust 的 `aarch64-apple-ios` target，运行 `scripts/build-airlift-ffi-ios.sh --install` 重建并安装归档，再用 XcodeGen 生成工程、`scripts/build-ipa.sh Release` 产出未签名 IPA（CI 的构建流程已经包含这一步）。本仓库的发行版提供已构建的未签名 IPA，下载后用自己的证书/账号自签安装。

界面文案为中文优先，直接以中文书写；继承自上游的向导等页面沿用其字符串目录。
